# skills

Скиллы для Claude Code и Claude.

| Скилл | Что делает |
|---|---|
| [unslop-document](skills/unslop-document/) | Вычитка русского текста, написанного с помощью ИИ: письма, посты, статьи, описания товаров, документация, договоры. Убирает штампы, кальки, канцелярит, рамки «не просто X, а Y», придуманные ярлыки без определения. Отдаёт таблицу «было → стало», смысл, цифры и голос автора не трогает. |

## Установка

Скопируйте папку скилла в `~/.claude/skills/`:

```bash
git clone https://github.com/Dgreat21/skills.git
cp -r skills/skills/unslop-document ~/.claude/skills/
```

Скилл подхватится в новой сессии. Его можно вызвать явно (`/unslop-document <файл>`) или просто попросить «причеши слог в <файл>».
